PROMPT STUDIO — TEST LOGICO SIMULATO — V1.0
=============================================
Obiettivo: simulare un utente reale dall'apertura fino alla generazione,
verificando che non debba mai chiedersi "dove devo andare adesso?".

------------------------------------------------------------------
TEST A — Percorso completo verso ComfyUI
------------------------------------------------------------------
1. Apro l'app -> Home con 3 grandi pulsanti (Crea personaggio/prompt,
   ComfyUI Studio, Genera con IA). Chiaro da dove iniziare. OK.
2. Premo "CREA PERSONAGGIO / PROMPT" -> Step 1/8, titolo "Chi vuoi
   creare?", due grandi pulsanti DONNA/UOMO, barra "PROMPT IN
   COSTRUZIONE" visibile (vuota). OK.
3. Premo DONNA -> avanzo automaticamente allo Step 2/8 "Corpo". La
   prompt bar ora mostra "1woman". OK.
4. Apro categoria "Corporatura" -> scelgo "Curvy". Apro "Seno" -> scelgo
   "Medio". Apro "Sedere" -> scelgo "Rotondo". La prompt bar si
   aggiorna in tempo reale con i tag inglesi corrispondenti. OK.
5. Premo Avanti -> Step 3/8 "Volto": scelgo "USA FOTO DI RIFERIMENTO".
   Compare il pulsante "Carica fotografia" -> import universale con 3
   sorgenti (Gestore file/Cloud, PC-ComfyUI, PC-file personali). Scelgo
   "Gestore file/Cloud" -> picker nativo del browser -> seleziono una
   foto -> anteprima mostrata, checkbox "Mantieni identità" spuntata di
   default. Il pulsante Avanti si abilita solo ora (prima era
   disabilitato in attesa della foto). OK — coerente con la regola
   "Identity Lock ha priorità elevata".
6. Premo Avanti -> Step 4/8 "Capelli": poiché esiste una foto di
   riferimento, la domanda è "Vuoi mantenere i capelli della
   fotografia?" con MANTIENI/CAMBIA. Scelgo CAMBIA -> si apre subito la
   libreria acconciature nella stessa schermata (nessuna navigazione
   altrove, come richiesto). Scelgo "Coda alta". OK.
7. Step 5/8 "Azione e posa": scelgo "Cammina" (azione) e "3/4"
   (posa). Campo testo libero disponibile per entrambe, con 🎙 dettatura
   e 🗑 cancella. OK.
8. Step 6/8 "Scena": scelgo "Città" + "Notte" + "Neon" (atmosfera).
   Campo "Descrivi la scena" lasciato vuoto. OK.
9. Step 7/8 "Camera e luce": scelgo "Medium shot", "3/4 sinistra",
   "Neon" (luce). OK.
10. Step 8/8 "Prompt finale": vedo PROMPT POSITIVO e PROMPT NEGATIVO
    già popolati e modificabili, libreria negativa con chip attivabili,
    pulsanti Copia positivo/negativo/tutto e "Salva personaggio in
    archivio". Premo "Salva personaggio" -> dialog nome -> "Elena" ->
    salvato. Poi vedo "Dove vuoi generare?" con 4 grandi pulsanti.
    Scelgo COMFYUI. OK — la destinazione è chiesta SOLO alla fine, come
    richiesto.
11. Navigazione automatica a ComfyUI Studio (hub). Lo stato del
    progetto (prompt positivo/negativo, foto reference) resta
    disponibile: nessun "trasferimento" manuale richiesto all'utente.
    OK.
12. Premo "CONFIGURAZIONE" -> imposto indirizzo Bridge, cartella
    ComfyUI, cartella personale -> "Salva e scansiona". Se il Bridge non
    è avviato, messaggio d'errore chiaro con invito a usare
    AVVIA_BRIDGE.bat (mai un fallimento silenzioso). OK.
13. Premo "INVENTARIO" -> vedo categorie richiudibili (Checkpoint, LoRA,
    VAE...) con badge verde/rosso/giallo di famiglia rilevata — mai
    dichiarato "compatibile" senza evidenza. OK.
14. Premo "LIBRERIA WORKFLOW" -> importo un JSON (import universale, le
    stesse 3 sorgenti di sempre) -> compare in lista -> "Seleziona".
    OK.
15. Vado su "EDITOR WORKFLOW" -> vedo solo i modelli/LoRA realmente
    presenti (dall'inventario), select/slider per checkpoint, LoRA
    (con peso), prompt positivo/negativo (con pulsante "Riempi da
    Prompt Studio"), seed/steps/cfg/denoise, width/height, nodi Load
    Image con assegnazione immagine. Editor JSON avanzato sempre
    disponibile in fondo (vedi/valida/applica/salva). OK.
16. Premo "Vai a Genera" -> "GENERA CON COMFYUI" -> stato "in coda" poi
    "completata" con immagine mostrata (zoomabile). OK.

Nessun punto del percorso ha richiesto di indovinare "dove vado adesso":
ogni schermata ha un titolo, una domanda, e un'azione successiva chiara.
