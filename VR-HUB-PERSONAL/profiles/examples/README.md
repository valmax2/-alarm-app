# Profili di esempio

Questi file mostrano lo schema di un `GameProfile` (spec §15/§53: import/export
profili) così com'è definito in `src/main/core/model/types.ts`. Non vengono
caricati automaticamente dall'app: sono un riferimento per chi vuole scrivere
o modificare un profilo a mano e poi importarlo (funzione di import prevista
per una fase successiva).

Per i profili effettivamente usati dall'app in Fase 1, vedi `database/catalog.json`.
