Voice Clone Studio

Clona la tua voce e genera audio in italiano, dal browser del PC — stesso account e stesse voci dell'app Android.

Usa lo stesso server locale (XTTS-v2) che magari già usi con l'app Android — server/xtts_server.py nel repository. Qui puoi scrivere localhost: il browser gira sullo stesso PC del server.

Qualità professionale via cloud. Serve la tua chiave API — la stessa che usi nell'app Android va bene qui.

Le tue voci

Tocca l'icona di regolazione per aggiustare i parametri e provare una voce già clonata — non serve mai riclonarla per cambiarli.

Testo → voce

Scegli una voce, scrivi (o detta) il testo e genera l'audio con le regolazioni salvate per quella voce.

Campioni originali (per confronto con la voce generata)

Conversione voce → voce

Registra o importa un audio con un'altra voce: viene ridoppiato con il timbro della voce clonata, mantenendo tempi e intonazione.

Non disponibile col server personale gratuito

XTTS-v2 fa clonazione da testo a voce, ma non converte un audio già registrato in un'altra voce. Per questa funzione serve il backend ElevenLabs — puoi cambiarlo in Impostazioni.

Rimuovi rumore di fondo
Ripulisce l'audio sorgente prima della conversione.

Usa la voce responsabilmente

Clona solo voci per cui hai un consenso esplicito. Clonare la voce di qualcuno senza permesso e usarla per ingannare o impersonare quella persona può essere illegale.

Dati su questo browser

Chiave API, indirizzo server e voci create con il backend gratuito restano solo in questo browser (localStorage/IndexedDB) — non vengono sincronizzati con l'app Android.
